# wavykit/core has moved

This package is now [`current/current`](https://packagist.org/packages/current/current),
developed at [currentphp/monorepo](https://github.com/currentphp/monorepo).
Version numbers continue: 0.3.0 is the first release under the new name.

```sh
composer remove wavykit/core
composer require current/current
```

The namespace changed from `WavyKit\` to `Current\`; see the
[changelog](https://github.com/currentphp/monorepo/blob/main/packages/current/CHANGELOG.md)
for every breaking change. Released versions of `wavykit/core` stay
installable, and this repository is archived.

Current is a [Wavy](https://wavy.dev) project.
